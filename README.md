# CS663 Project 1 — GitHub Pages Tutorial

**Topic:** Computer Vision for Pet Behavior Monitoring and Restricted-Area Detection  
**Author:** Fei Pei

This folder is a complete static GitHub Pages website. No build system is required.

## Files

- `index.html` — introduction and problem definition
- `tracking.html` — pet detection and tracking
- `restricted-area.html` — polygon zone, point-in-polygon, dwell-time algorithm
- `behavior.html` — dog behavior recognition and research comparison
- `limitations.html` — challenges, limitations, and future research
- `demo.html` — interactive restricted-zone demo and 5-question quiz
- `bibliography.html` — annotated bibliography
- `css/style.css` — site design
- `js/site.js` — navigation highlighting and page voice/text-to-speech
- `js/demo.js` — interactive demo and quiz
- `images/` — six original SVG diagrams

## Publish on GitHub Pages

1. Upload everything in this folder to the **root** of your `cs663-project1` repository.
2. Keep the file name `index.html` exactly as written.
3. Go to **Settings → Pages**.
4. Source: **Deploy from a branch**.
5. Branch: **main** and folder: **/(root)**.
6. Save and wait for GitHub Pages to deploy.

## Important before submission

The site already contains browser text-to-speech on every page. If your professor specifically expects **your own recorded voice** rather than a browser-generated voice, record short MP3 narration files and replace/add audio players before submission.

Also check every DOI link, read through the wording so you can explain it during your presentation, and make any personal edits you want. Do not submit material you cannot explain.
